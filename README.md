# 크보 (kbo-android)

KBO 프로야구를 보는 안드로이드 앱. 응원 팀을 하나 고르면 그 팀의 경기 결과와
하이라이트 영상을 모아 보여주고, 경기가 끝나거나 새 영상이 올라오면 알림을 보낸다.

## 화면

| 탭 | 내용 |
|----|------|
| 오늘 | **내 팀 라이브** / 최근 결과 / 다음 경기 / 오늘 전체 경기 |
| 영상 | **라이브(최대 3)** / KBO 공식 채널에서 내 팀 영상만 (하이라이트 · 크보모먼트 필터) |
| 설정 | 팀 변경, 알림 on/off, 유튜브 API 키 |

내 팀 경기가 진행 중이면 오늘 탭 맨 위에 이닝·점수와 함께 고정된다. 다른 팀 라이브는
아래 "오늘 경기" 목록에 이닝 표시로 남는다.

## 영상 탭 라이브

맨 위에 지금 방송 중인 내 팀 라이브가 최대 3개 올라간다.

1. **구단 공식 채널 라이브** (항상 먼저) — 최신 업로드 15개를 `videos.list` 로 확인. 2 유닛.
   공식 채널은 1군 경기를 중계하지 않지만(중계권이 티빙) 퓨처스 생중계, 경기 전 프리뷰,
   은퇴식 같은 행사를 라이브로 한다.
2. **유튜브 전체 라이브** — 내 팀 경기가 실제로 진행 중일 때만 검색한다(100 유닛).
   경기 중 라이브는 입중계와 지역 방송사 라디오 중계가 대부분이다. 시청자 많은 순.

전체 검색은 **해시태그 도배** 때문에 그대로 쓸 수 없다. 2026-09-18 LG vs KT 경기 중
"LG트윈스" 라이브 검색 시청자 1위(1,168명)는 `#lg트윈스` 태그만 붙인 삼성 vs 한화 입중계였다.
그래서 태그를 뗀 제목에서 팀을 읽고, 내 팀이 나오며 다른 팀이 나온다면 그게 오늘 상대일
때만 통과시킨다. 팬들이 쓰는 이름(엘지, 기아, 케이티, 엔씨, 트윈스, 위즈 …)도 인식한다.

구단 공식 채널 ID 는 팀명 검색 결과를 그대로 쓰지 않고, 채널 설명에 공식 채널이라고
적힌 것만 골라 `Team.kt` 에 넣었다 (KIA 는 검색 1위가 팬 채널이다).

라이브는 영상 탭에 들어올 때 확인하고, 1분 안에 다시 들어오면 건너뛴다. 새로고침 버튼은 즉시 다시 조회한다.

경기를 누르면 상세 화면에서 **이닝별 스코어보드(R/H/E/B)**, **승리·패전투수와 세이브**,
**결승타**, **홈런**, **양 팀 순위**를 본다. 그 경기의 하이라이트 영상이 있으면 같이 붙는다.

## 데이터 출처

두 곳을 쓴다. 나눈 이유가 있다.

- **영상 — YouTube Data API v3.** KBO 공식 채널(`@KBO1982`, `UCoVz66yWHzVsXAFG8WhJK9g`)의
  업로드 재생목록을 읽는다. `search.list`(호출당 100 유닛) 대신
  `playlistItems.list`(호출당 1 유닛)를 쓰고 팀 필터는 앱에서 건다. 주기 알림이
  하루 종일 돌아도 일일 할당량 10,000 유닛에 여유가 많다.
- **점수·기록 — 네이버 스포츠 공개 KBO 엔드포인트.** 키가 필요 없다.

점수를 유튜브에서 안 가져오는 건 **거기 없기 때문**이다. 공식 채널 하이라이트 제목은
`[NC다이노스 vs 두산베어스] 9.12(토) 야구 하이라이트｜2026 KBO 리그｜KBO X TVING`
형식이고 설명란에도 스코어가 없다. 제목에서 점수를 추측해 지어내지 않고,
실제 스코어가 있는 곳에서 읽어 온다.

그래서 **API 키가 없어도 경기 일정·스코어·요약·알림은 전부 동작한다.** 키는 영상 탭에만 필요하다.

## 유튜브 API 키 넣기

둘 중 아무 쪽이나.

1. `local.properties` 에 넣고 다시 빌드
   ```
   YOUTUBE_API_KEY=AIza...
   ```
2. 앱 실행 후 **설정 → 유튜브 → API 키** 에 붙여넣고 저장 (이쪽이 빌드에 심은 키보다 우선)

키는 [Google Cloud Console](https://console.cloud.google.com) 에서
`YouTube Data API v3` 를 켜고 API 키를 발급받으면 된다.

## 알림

`WorkManager` 로 30분마다 확인한다.

- **경기 결과** — 내 팀 경기가 끝나면 `LG 승 · 4-3 vs 삼성` 같은 제목에 승리투수·결승타를 붙여 보낸다.
- **새 영상** — 내 팀 하이라이트가 올라오면 알린다. 누르면 유튜브로 바로 간다.

같은 경기·영상으로 두 번 울리지 않게 알린 기록을 남긴다. 알림을 처음 켠 회차에는
기존 영상이 전부 "새 영상"으로 잡히므로 그 회차는 기록만 남기고 넘어간다.

Android 13(API 33) 이상에서는 알림 권한이 필요하다. 설정 탭에서 요청할 수 있다.

### 경기 상태 코드

네이버가 돌려주는 `statusCode` 는 네 가지이고, 전부 실제 응답에서 확인했다.

| statusCode | statusNum | 뜻 | 앱에서 |
|---|---|---|---|
| `BEFORE` | 0 | 경기 전 | 경기 전 |
| `READY` | 1 | 개시 직전 | **경기 전** (아직 시작 아님) |
| `STARTED` | 2 | 진행 중 (`statusInfo` 에 "3회초") | 라이브 |
| `RESULT` | 4 | 종료 | 종료 |

`cancel` 플래그는 상태 코드보다 우선한다. `READY` 를 라이브로 잡으면 시작도 안 한 경기가
최상단에 올라가므로 `STARTED` 만 라이브로 본다.

`KboTitleParser` 는 공식 채널에 실제로 올라온 제목으로 검증한다. 전각(`｜`)·반각(`|`)
구분자, `|  vs  |` 처럼 팀 칸이 빈 제목, `NC  vs 한화` 같은 겹공백, 퓨처스리그(2군) 제외,
`LANCE` 안의 `NC` 같은 오탐 방지가 테스트에 들어 있다.
